# Silero reference traces

One probability per 512-sample (32 ms at 16 kHz) window, generated by ONNX Runtime from
`third_party/silero-vad/silero_vad_16k_op15.onnx` via `tools/silero/make_reference.py`.

`SileroVadTest` asserts the hand-written C++ forward pass against these. They are the reason
ONNX Runtime is not a dependency of this project: the runtime that shipped 32 MB per ABI is
replaced by a few kilobytes of committed numbers plus a script to regenerate them.

`synthetic.wav` is the generated signal behind `synthetic.txt` — silence, noise, a modulated
harmonic stack and a tone — committed so the C++ test can run byte-identical audio. It is the
widest-range clip and the one most likely to catch a gate-order or stride error.

Do not hand-edit. If the vendored model changes, re-run the tool; if the C++ changes and these
stop matching, the C++ is what is wrong — unless the C++ change is a deliberate retune (e.g. the
decimator's filter), in which case a mismatch is expected until these traces are regenerated
against it, and the traces are what should move.
